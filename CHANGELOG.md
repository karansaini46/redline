# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive SEO optimization across all Next.js routes.
- Dynamic `sitemap.xml` and `robots.txt` generation.
- FAQPage JSON-LD schema on the landing page for enhanced search engine visibility.
- Centralized architecture documentation (`docs/architecture.md`).
- `CONTRIBUTING.md` and standard open-source files.

### Changed
- Elevated the platform UI to a premium, monochromatic design system with enhanced micro-animations.
- Improved CI pipeline stability with zero-warning lint enforcement and robust Vitest integration.
- Refined the background extraction pipeline (Redis) to reliably score clauses for risk metrics.

## [1.0.0] - 2026-07-01

### Added
- Initial release of the Redline Platform.
- AI-powered contract analysis using Google Gemini.
- Full PDF ingestion and chunking pipeline.
- Row-Level Security for multi-tenant data isolation.
- Dashboard with real-time portfolio metrics.
